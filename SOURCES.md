`unattributed/` directory declare no licence, which by default means the authors
reserve all rights. They are included because this repository is **private and
used as an archive**. If it is ever made public, remove them first:

    git rm -r skills/Eyadkelleh_awesome-skills-security \
             skills/Gabson0x_bountyforge \
             skills/unattributed

`trailofbits_skills` is CC BY-SA 4.0 (share-alike). Keeping it as an unmodified
vendored directory preserves its notice; any adaptation of those files must stay
under CC BY-SA 4.0.

## Revision drift

The archive was assembled on 2026-10-30 and vendors the upstream revisions then
on disk (`/home/logic/tools/skill-repos`, plus the `Claude-BugHunter` checkout at
commit `a9e5a01`). Nineteen skills differ from the copies installed in September:
the archive holds the newer upstream body, and the September `SKILL.md` text is
not duplicated here. `provenance/catalog-manifest-2026-09-10.json` records the
installed name → upstream mapping and the installed/upstream SHA-256 pairs for
that older snapshot.

# HackingHub — hubs with a published completer writeup

Generated by scanning `api.hackinghub.io/hubs/<slug>/leaderboard` for the `writeup` field on every
scored mission/challenge hub. **This is the single highest-yield index for this platform** — it
opened both Swag Shop and VulnLab completely, and it hands over the Starcraft root step.

```bash
# regenerate
curl -s https://api.hackinghub.io/hubs/<slug>/leaderboard | python3 -m json.tool | grep writeup
```

**Always check this before starting a hub.** It has been the decisive move three times.

---

## 0. Check the hub's OWN `video` field first — it is sometimes the author solving that exact lab

`GET https://api.hackinghub.io/hubs/<slug>` returns, alongside `content`, a **`video`** field. For hubs the
author built from a talk or stream, that video is **their own narrated walkthrough of this exact
lab** — and the transcript hands over the intended path in plain English. `feeling-lucky` was stuck at
3/5 across four rounds against every API-level angle; the `video` field pointed at NahamSec's DEF CON 31
casino talk, whose subtitle track says, verbatim, *"a couple of them I brute-forced for it and it worked"*
and *"an unrestricted upload … upload a shell"*. The two remaining flags fell in one pass.

```bash
curl -s -H "Cookie: token=$(cat ../../.hhtoken)" https://api.hackinghub.io/hubs/<slug> \
  | python3 -c "import json,sys;print(json.load(sys.stdin)['hub']['video'])"
# then, if it is a YouTube link:
yt-dlp --write-auto-subs --write-subs --skip-download --sub-langs "en.*" --sub-format vtt -o sub \
  "https://www.youtube.com/watch?v=<id>"
# VTT auto-captions are karaoke-tagged; strip them to readable text first:
#   re.sub(r"<[^>]*>", "", line) per line, drop lines containing "-->"
```

**Cost of not doing this:** four rounds of `feeling-lucky` re-derivation that the video answers in its
first two minutes. Check `video` **before** the leaderboard-writeup table — it is always present
(`linked_course`, `downloads` and `submodules` are frequently empty; `video` was not).

**Also check `hub.content_markdown` in full first** — it sometimes ships the credentials to use
(`oauth-ato` hands over `admin@itsupport.ctf:password`). And when the video *shows* a URL it never speaks
(`ghost-api`), extract frames with `ffmpeg -vf fps=1/2` and read the relevant one with the **image** tool —
tesseract garbles a browser URL bar that the image renders cleanly.
